# Laboratorio de Eliminación Urinaria

Recorrido interactivo por un piso de hospital para la clase de **atención durante la eliminación urinaria** (Universidad FUCS, estudiantes militares).

**Ver el laboratorio:** https://andresarangoez.github.io/laboratorio-eliminacion-urinaria/

## Paradas
1. Recepción: motivación, competencias y caso de ingreso
2. Sala de anatomía: riñón, uréter, vejiga y uretra; actividad para rotular
3. Estación de enfermería: control de líquidos, pérdidas insensibles, balance de 24 h y gasto urinario
4. Unidad renal: alteraciones del riñón (antes, dentro y después del riñón), diálisis peritoneal y hemodiálisis
5. Almacén de material: sondas Nelaton y Foley, Cystoflow y preguntas
6. Habitación 101: sondaje vesical en la mujer
7. Habitación 102: sondaje vesical en el hombre
